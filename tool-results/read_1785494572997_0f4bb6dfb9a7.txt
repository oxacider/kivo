    15→| `mini-services/kivo-chat-service/index.ts` | Main Socket.io server on port 3003 |
    16→
    17→### Socket Events Handled
    18→| Event | Direction | Description |
    19→|-------|-----------|-------------|
    20→| `auth` | client→server | Authenticate with userId, mark online |
    21→| `message:send` | client→server | Save message to DB, emit `message:new` to recipient |
    22→| `message:edit` | client→server | Update message content, emit `message:updated` |
    23→| `message:delete` | client→server | Soft-delete, emit `message:deleted` |
    24→| `message:read` | client→server | Mark as read, emit `message:read` to sender |
    25→| `typing:start` | client→server | Emit `user:typing` with isTyping: true |
    26→| `typing:stop` | client→server | Emit `user:typing` with isTyping: false |
    27→| `user:status` | client→server | Update status text, broadcast `user:status-change` |
    28→| `disconnect` | automatic | Mark offline, broadcast `user:offline` |
    29→
    30→### Key Design Decisions
    31→- `path: '/'` on Socket.IO (required for Caddy reverse-proxy routing)
    32→- Uses parent project's `db` client via `import { db } from '../../src/lib/db'`
    33→- Two maps for tracking: `onlineUsers` (userId→socketId) and `socketToUser` (socketId→userId)
    34→- Graceful shutdown via SIGTERM/SIGINT handlers
    35→
